# Vandalia Chess Club

A responsive website for a made-up chess club in Vandalia, Ohio, where I live. This was the responsive design project on Codecademy's Full-Stack Engineer path. You pick any club and build a site for it that works on every screen size, and I went with chess.

The site has a hero section, an about section, the weekly schedule (Tuesday, Thursday, and Saturday meetups), and membership options for drop-in or monthly.

It's laid out with Flexbox and has two breakpoints: at 768px the sections stack into columns for tablets, and at 480px everything tightens up for phones. The best way to see it work is to open it and drag the browser window narrower.

## Running it

Clone the repo and open `index.html` in your browser.
